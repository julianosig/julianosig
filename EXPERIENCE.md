## Selected engineering experience

### easi.run · Creator & maintainer

**Open-source browser infrastructure for people and AI agents.**

The project combines self-hosted Chrome sessions with MCP and REST interfaces, live viewing, saved browser state and human takeover. Its public repository includes the implementation, architecture, security boundaries, deployment instructions and benchmark methodology.

- **Agent integration:** tools for browser interaction, file transfers, session discovery and resuming saved profiles; optional CDP connectivity for existing browser scripts.
- **Systems engineering:** a Rust Wayland compositor, display protocol, streaming pipeline and browser-facing TypeScript viewer.
- **Human control:** a control lease and handoff workflow so a person can complete interactive steps while agent actions wait.
- **Session boundaries:** containerized components, restricted egress, per-agent permissions and encrypted persistent browser profiles.
- **Product delivery:** an admin interface, session timeline and replay, documentation, public demo and self-hosted installation flow.
- **Verification:** CI checks, end-to-end tests, fuzz targets and benchmarks with a published methodology.

**Stack:** Rust, TypeScript, Svelte, Chrome, MCP, Docker, Linux, WebSocket, WebTransport, AV1.

[Repository](https://github.com/julianosig/easi.run) · [Architecture](https://github.com/julianosig/easi.run/blob/main/docs/architecture.md) · [Security boundaries](https://github.com/julianosig/easi.run/blob/main/docs/security.md) · [Benchmark method](https://github.com/julianosig/easi.run/blob/main/docs/benchmark.md)
